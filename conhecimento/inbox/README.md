# inbox/ — material bruto

Jogue aqui qualquer material novo para o cérebro da Bia (PDFs, anotações, planilhas).
Nada daqui entra no build (`kb:build` ignora este diretório) até passar pela curadoria:

1. Ler e reescrever no formato do cérebro (ver `../AGENTS.md`).
2. Catalogar a fonte em `../fontes.md` e o arquivo em `../INDEX.md`.
3. Regenerar (`npm run kb:build`) e validar (`npm run kb:check`).
4. Remover o item processado daqui (o histórico fica no git).
